# 注意
1. moco-odoo-client_xxx_xx_g(h)ms.apkは、16+の最新のコミュニティ（2024/05/01以降のコードベース）およびエンタープライズバージョンをサポートします。これは長期サポートバージョンであり、GMSとHMSの両方の主要なAndroidプラットフォームをサポートします。
2. v14エンタープライズ版を特別にサポートします。
3. v14e/moco-odoo-client-v1.apkはv14エンタープライズ版のみをサポートし、今後はサポートされません。
4. コミュニティ版では、より良い体験のために無料または有料のモバイルテーマをインストールすることをお勧めします。
5. HarmonyOS / Androidのスマートフォンとタブレットをサポートします。
6. サーバー側でのインストールが不要な連続スキャンをサポート！箱から出してすぐに使えます！
7. Bluetoothサーマル印刷/ IPPプロトコルの通常印刷をサポートし、モジュールをインストールする必要はありません！
8. 継続的に開発および反復されています。質問や機能の提案は、issueで歓迎します。
